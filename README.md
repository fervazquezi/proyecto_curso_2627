# proyecto_curso_2627

# Problema a resolver:
El usuario es una persona que le gusta mucho jugar a videojuegos y debido a eso tiene una mala condicion fisica, por lo que le gustaria realizar un cambio fisico, pero le cuesta mucho mantener una disciplina a largo plazo realizando actividad fisica porque no le gusta, lo encuentra aburrido y tedioso, lo que lo lleva a desmotivarse, volviendo a los tipicos videojuegos en el escritorio.

# Datos del problema

## Introduccion de datos
El usuario selecciona el ejercicio que va a realizar e introduce la cantidad de repeticiones con el peso que ha hecho de ese ejercicio, ya que no existe ningún sensor o registro automático que capture esta información — el usuario actualmente lleva la cuenta de sus repeticiones y peso de memoria, así que solo él puede reportar estos datos al sistema

## procesamiento
El sistema dividira los ejercicios en cinco grupos musculares: piernas, abdomen, espalda, pecho y brazos. Cada ejercicio tendra una ponderacion asociada en funcion del grupo muscular trabajado. A partir del peso utilizado y del numero de repeticiones realizadas, el sistema calculara una puntuación que se utilizara para obtener experiencia y subir de nivel al personaje. De esta forma, el mismo peso y numero de repeticiones no tendran necesariamente la misma puntuacion en ejercicios que trabajen diferentes grupos musculares.

Además, se podrán otorgar recompensas, como disfraces u otros elementos personalizables para el personaje, cuando el usuario mantenga una racha activa de dias entrenando. Asi, la constancia en la actividad fisica tambien tendra un impacto en la progresión del personaje

## Despliegue en la nube
Se utilizara despliegue en la nube para generar duelos online en los que tu personaje del videojuego se pueda enfrentar al personaje de otra persona, en los que se pondrá un resto comun de cada grupo muscular a ambos personajes, por ejemplo hacer x repeticiones de un ejercicio, y quien haga mejor putuacion de media gana el duelo
